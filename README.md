# 自由軒 Webサイトリニューアル

高知県の老舗ラーメン店「自由軒」のWebサイトをリニューアルしたという想定で制作した自主制作作品です。

## リニューアル対象

元サイト：  
https://ramen-ziyuuken-grupe.crayonsite.net/

作成したサイト：
https://tsujikota088.github.io/ramen-jiyuuken-kochi/

※本作品は個人学習・ポートフォリオ目的で制作した非公式のリニューアル案です。

## 制作背景

元サイトを見た際、

- 複数店舗の情報が混在していて探しづらい
- 情報の優先順位がわかりにくい
- 看板メニューの「味噌カツラーメン」が魅力的に見えない

という課題を感じました。

そこで、

**「自由軒に行きたくなるサイトを作る」**

ことをテーマに、情報整理とデザイン改善を行いました。

## Before / After

| Before | After |
|----------|----------|
| 店舗情報とメニュー情報が混在 | 情報を整理し、目的別に閲覧しやすく改善 |
| 看板商品の訴求が弱い | ファーストビューで味噌カツラーメンを訴求 |
| 情報の優先順位が不明確 | コンテンツを見やすく再構成 |

## 使用技術

- HTML
- CSS

## 工夫した点

- 既存サイトの情報量は大きく増やさず再構成
- メニューを主役にしたレイアウト設計
- ユーザーが知りたい情報へたどり着きやすい導線を意識
